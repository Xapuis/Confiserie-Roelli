# Confiserie Roelli — Official Website

Complete redesign and development of the official website for Confiserie Roelli, an artisan bakery, pastry shop and confectionery founded in 1958 in Porrentruy, Jura, Switzerland.

## Tech stack
- HTML5, CSS3, JavaScript (vanilla)
- Multilingual: FR / DE / EN / IT
- WebP image optimization
- Apache security configuration
